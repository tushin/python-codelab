STEP 4

Detecting Collisions

In this lesson, we will implement the core logic for collision detection. Without it, your snake could pass through its own tail or travel indefinitely past the laboratory boundaries.

lightbulb Key Concept

Collision detection in a grid-based game is as simple as comparing the (x, y) coordinates of the head with every (x, y) coordinate in the body array.

Instructions

  • 1. Access the snake_head coordinates.
  • 2. Loop through the snake_body segments.
  • 3. Return True if a match is found.

def check_collision(snake_head, snake_body):
    """
    Checks if the snake head has collided 
    with any part of its body.
    """
    for segment in snake_body[1:]:
        if snake_head.x == segment.x and \
           snake_head.y == segment.y:
            return True
            
    return False
